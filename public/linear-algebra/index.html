Linear Algebra

Vectors, matrices, elimination, vector spaces, orthogonality, determinants, eigenvalues, SVD — the language of portfolios and factor models.

Chapters 01–07 are live · new chapters open in order

How to use this subject

Pick a chapter from the sidebar and work it top to bottom. Inside a chapter, every lesson has a Notes tab that explains each word from zero and an Examples tab whose first example is an interactive Nifty lab — change the inputs, predict the answer, then scroll to check.

Why this subject is first

Every portfolio is a vector, every hedge is a system of equations, every factor model is a projection. The rest of the maths roadmap — probability, statistics, time-series, stochastic calculus — speaks this language.
