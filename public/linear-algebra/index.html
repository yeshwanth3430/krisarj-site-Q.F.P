How to use this subject

Pick a lesson from the sidebar and work it top to bottom. Every lesson has a Notes tab that explains each word from zero and an Examples tab whose first example is an interactive Nifty lab — change the inputs, predict the answer, then scroll to check.

Why this subject is first

Every portfolio is a vector, every hedge is a system of equations, every factor model is a projection. The rest of the maths roadmap — probability, statistics, time-series, stochastic calculus — speaks this language.

What you'll walk away with

By the end you can set up and solve any hedge as Ax = b, read a matrix's rank and four subspaces to know which targets a book of products can and cannot reach, and project one return onto others — which is exactly beta, regression and factor models.
