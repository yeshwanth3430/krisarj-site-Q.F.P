Linear Transformations and their Matrices

What we are solving

$$ \boxed{\text{The transformation comes first. The matrix is only its description in a basis.}} $$

Everything so far started from a matrix. This lesson turns that round: start with a geometric rule — rotate, project, reflect — and ask what makes it linear, then build the matrix from it. Choosing a different basis gives a different matrix for the same transformation, and choosing well can make it diagonal.

The two requirements ★

\(T\) is linear when, for all vectors and all scalars,

$$ \boxed{T(v + w) = T(v) + T(w)} \qquad\text{and}\qquad \boxed{T(cv) = cT(v)} $$

Combined: \(T(cv + dw) = cT(v) + dT(w)\). An immediate consequence is \(T(0) = 0\).

Part 2 The lecture

1. A transformation without coordinates

Describe projection onto a line without writing a single number:

"Take any vector in the plane. Drop a perpendicular onto the fixed line. The foot of that perpendicular is where the vector goes."

That is a complete rule. It takes every \(v\) in \(\mathbb{R}^2\) to some \(T(v)\) in \(\mathbb{R}^2\), written

$$ T : \mathbb{R}^2 \longrightarrow \mathbb{R}^2 $$

No basis, no coordinates, no matrix — and you can already picture what it does to a whole drawing.

Why start here

A matrix is a grid of numbers that depends on a choice of coordinates. The transformation is the thing itself. Seeing them as separate explains why one transformation has many matrices, and why some of those matrices are much nicer than others.

2. What linear means

Not every rule deserves a matrix. The ones that do are the linear ones.

Definition · linear transformation ★ $$ T(v + w) = T(v) + T(w) \qquad\text{and}\qquad T(cv) = cT(v) $$

for all vectors \(v, w\) and all scalars \(c\). Equivalently, in one line:

$$ \boxed{T(cv + dw) = cT(v) + dT(w)} $$

In words: \(T\) commutes with adding and scaling. Combine first and transform, or transform first and combine — same answer.

A consequence to check first

Put \(c = 0\) in the second rule:

$$ T(0) = T(0 \cdot v) = 0 \cdot T(v) = 0 $$ $$ \boxed{T(0) = 0 \text{ for every linear transformation}} $$

A quick disqualifier: if a rule moves the origin, it is not linear, and you need check nothing else.

3. Two things that are not linear

Shifting the whole plane

$$ T(v) = v + v_0 \qquad\text{for a fixed non-zero } v_0 $$

Check the scaling rule with \(c = 2\):

ExpressionValue
\(T(2v)\)\(2v + v_0\)
\(2T(v)\)\(2(v + v_0) = 2v + 2v_0\)

These differ by \(v_0 \ne 0\). Not linear ✗ — and \(T(0) = v_0 \ne 0\) said so immediately.

A shift is "linear" in ordinary speech, not in this subject

The map \(x \mapsto 3x + 5\) draws a straight line, and school calls it linear. Here it is affine, not linear, precisely because of the \(+5\). Linear transformations fix the origin; that is the whole difference.

Taking a length

$$ T(v) = \|v\| $$

Try \(c = -1\):

ExpressionValue
\(T(-v)\)\(\|-v\| = \|v\|\) — length is never negative
\(-T(v)\)\(-\|v\|\)

These differ whenever \(v \ne 0\). Not linear ✗ (It also fails addition: \(\|v + w\| \le \|v\| + \|w\|\), with equality only when they point the same way.)

4. More examples

Rotation by 45°

\(T\) turns every vector 45° counterclockwise about the origin. Linear: rotating a sum rotates both pieces, and rotating a stretched vector stretches the rotated one. Easy to see, no coordinates needed.

What the geometric view buys

Told "rotate by 45°", you instantly know what happens to a drawing of a house. Handed the matrix

$$ \frac{1}{\sqrt2}\begin{bmatrix} 1 & -1 \\ 1 & 1 \end{bmatrix} $$

you would have to work it out. Same transformation, and the geometric description is the one you can think with.

Reflection

$$ T(v) = Av, \qquad A = \begin{bmatrix} 1 & 0 \\ 0 & -1 \end{bmatrix} $$

This keeps the \(x\) component and flips the sign of \(y\) — a reflection across the \(x\)-axis. Doing it twice returns you to the start, and indeed \(A^2 = I\) ✓

Every matrix is a linear transformation

Given any \(A\), define \(T(v) = Av\). Both rules are matrix algebra:

$$ A(v + w) = Av + Aw, \qquad A(cv) = c(Av) $$

So \(T\) is linear ✓. And a matrix need not be square: a \(2 \times 3\) matrix gives \(T : \mathbb{R}^3 \to \mathbb{R}^2\).

5. How much do you need to know?

To specify \(T\) you would seem to need \(T(v)\) for infinitely many \(v\). You do not.

The key fact ★

Write \(v = c_1v_1 + \dots + c_nv_n\) in a basis. Then linearity gives

$$ \boxed{T(v) = c_1T(v_1) + c_2T(v_2) + \dots + c_nT(v_n)} $$

So \(n\) pieces of information determine \(T\) completely. That finiteness is exactly why a matrix can exist.

The numbers \(c_1, \dots, c_n\) are the coordinates of \(v\) in that basis. Change the basis and the coordinates change — the vector does not.

6. Building the matrix

Method · the matrix of a transformation ★

Choose a basis \(v_1, \dots, v_n\) for the input space and \(w_1, \dots, w_m\) for the output space. Then:

  1. Apply \(T\) to the first basis vector.
  2. Write the result in the output basis: \(T(v_1) = a_{11}w_1 + a_{21}w_2 + \dots + a_{m1}w_m\).
  3. Those coefficients are column 1 of \(A\).
  4. Repeat for each \(v_i\) to get column \(i\).
$$ \boxed{\text{column } i \text{ of } A = \text{the coordinates of } T(v_i)} $$

With \(A\) built this way, \(T(v) = Av\) holds for every \(v\) — it holds on each basis vector by construction, and linearity carries it to all combinations.

7. The standard basis

Take \(T\) = projection onto the line \(y = x\), and use the standard basis \(e_1 = (1,0)\), \(e_2 = (0,1)\) for both input and output.

The line \(y = x\) has unit direction \(\tfrac{1}{\sqrt2}(1,1)\). From Lesson 14, projecting \(b\) onto a line through \(a\) gives \(\dfrac{a^Tb}{a^Ta}a\). With \(a = (1,1)\) and \(a^Ta = 2\):

Input\(a^Tb\)\(T(v) = \tfrac{a^Tb}{2}a\)
\(e_1 = (1,0)\)\(1 + 0 = 1\)\(\tfrac12(1,1) = \left(\tfrac12, \tfrac12\right)\)
\(e_2 = (0,1)\)\(0 + 1 = 1\)\(\tfrac12(1,1) = \left(\tfrac12, \tfrac12\right)\)

Those are the columns:

$$ A = \begin{bmatrix} 1/2 & 1/2 \\ 1/2 & 1/2 \end{bmatrix} $$

Four fractions, and the structure is a little buried.

8. A better basis

Nothing forced the standard basis. Choose one fitted to the problem:

$$ v_1 = \frac{1}{\sqrt2}\begin{bmatrix} 1 \\ 1 \end{bmatrix} \ \text{(along the line)}, \qquad v_2 = \frac{1}{\sqrt2}\begin{bmatrix} 1 \\ -1 \end{bmatrix} \ \text{(perpendicular to it)} $$

Use the same basis for input and output, and apply \(T\):

Input\(T(v_i)\)In the basisColumn
\(v_1\)\(v_1\) — already on the line, so unmoved\(1 \cdot v_1 + 0 \cdot v_2\)\(\begin{bmatrix} 1 \\ 0 \end{bmatrix}\)
\(v_2\)\(0\) — perpendicular, so entirely error\(0 \cdot v_1 + 0 \cdot v_2\)\(\begin{bmatrix} 0 \\ 0 \end{bmatrix}\)
$$ \boxed{A' = \begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}} $$
Same transformation, far better matrix ★

\(A = \begin{bmatrix} 1/2&1/2 \\ 1/2&1/2 \end{bmatrix}\) and \(A' = \begin{bmatrix} 1&0 \\ 0&0 \end{bmatrix}\) describe the identical projection. Only the coordinates differ.

And \(A'\) says everything at a glance: one direction kept (eigenvalue 1), one direction destroyed (eigenvalue 0). It is diagonal, so \(A'^2 = A'\) needs no computation.

These two matrices are similar in the exact sense of Lesson 27 — \(A' = S^{-1}AS\) with \(S\) the matrix of the new basis. And the basis that diagonalised it was the basis of eigenvectors, which is what Lesson 21 was doing all along.

The theme of the whole course

Lesson 16 chose orthonormal bases to kill the inverse. Lesson 21 chose eigenvectors to make powers cheap. Lesson 22 chose them to decouple a system. Lesson 28 chose two bases at once for the SVD.

Every one of those is this lesson's idea: the transformation is fixed; pick the coordinates that make its matrix simple.

What he emphasised

  1. The transformation is the object ★The matrix is a description that depends on a choice you made.
  2. Linearity is what makes matrices possibleIt is the reason \(n\) pieces of information determine \(T\) on infinitely many vectors.
  3. Check \(T(0) = 0\) firstOne substitution, and it rules out every affine map.
  4. Geometry first, coordinates second"Rotate by 45°" is easier to think about than any matrix of it.
  5. Choosing the basis is the whole game ★Same projection: four fractions, or a clean \(\mathrm{diag}(1,0)\).
