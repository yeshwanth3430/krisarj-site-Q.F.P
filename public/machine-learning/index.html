Machine Learning

Five books, in the order they are worth reading.

01

Hands-On Machine Learning with Scikit-Learn and PyTorch

Aurélien Géron · 2025

Best overall for practical ML using existing libraries. Covers regression, classification, ensembles, model tuning, and deep learning.

Scikit-learn · PyTorch · NumPy · Pandas

02

Introduction to Machine Learning with Python

Andreas C. Müller & Sarah Guido

Best for beginners. Teaches how to use existing ML algorithms without requiring you to implement their mathematics from scratch.

Scikit-learn · NumPy · Pandas · Matplotlib

Older API examples may need adjustments.

03

Machine Learning with PyTorch and Scikit-Learn

Sebastian Raschka, Yuxi Liu & Vahid Mirjalili

Excellent for understanding algorithms while writing practical Python code. Strong progression from classical ML into neural networks.

Scikit-learn · PyTorch · NumPy

04

Machine Learning with Python Cookbook, 2nd Edition

Chris Albon

Best as a practical reference. Contains recipes for preprocessing, feature engineering, training, evaluating, and tuning models.

Scikit-learn · Pandas · NumPy

05

Machine Learning for Algorithmic Trading, 2nd Edition

Stefan Jansen

Best for applying ML to financial markets, alpha factors, financial datasets, and trading strategies.

Scikit-learn · LightGBM · XGBoost · Pandas · deep-learning tools
